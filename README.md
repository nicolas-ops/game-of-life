# Conway's Game of Life

A lightweight terminal implementation of John Conway's Game of Life written in C++.

## Features

- Fully terminal-based grid rendering
- Smooth frame execution and state updates
- Configurable initial states and grid boundaries

## Prerequisites

- C++17 compatible compiler (`g++` or `clang++`)
- `make` 
- `ncurses` (if terminal control is linked)

## How to play

- `Mouseclick` to place/remove pixels
- `Space` to pause/unpause
- `r` to place random pixels
- `g` to spawn a glider at last clicked spot
- `q` to quit

## Build & Run

Compile the source code using `make`:

Build: `make all`

Run: ./src/GameOfLifeMain
